⚙️ Firebase setup required

This tool needs a free Firebase Realtime Database to sync check-ins live across devices. One-time setup, ~10 minutes.

  1. Go to console.firebase.google.com and create a project.
  2. In your project: Build → Realtime Database → Create Database → Test mode → Enable.
  3. Copy the Database URL (e.g. https://your-project-default-rtdb.firebaseio.com).
  4. Go to ⚙ Project settings → Your apps → </> Web → Register app. Copy the apiKey.
  5. Open this HTML file in any text editor. Find PASTE_YOUR_API_KEY_HERE and PASTE_YOUR_DATABASE_URL_HERE and replace them.
  6. Save and reopen in your browser — setup done.

To go live for your team: upload the file to GitHub and enable GitHub Pages (see your setup guide).
